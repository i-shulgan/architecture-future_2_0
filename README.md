| Папка | Содержание |
|---|---|
| [Task1](Task1/README.md) | Целевая архитектура через год (C4 Container), проблемные места, приоритизация (MoSCoW, матрица Эйзенхауэра) |
| [Task2](Task2/README.md) | Домены и их обоснование, DFD уровней 0 и 1, бизнес-сценарии в потоках данных |
| [Task3](Task3/README.md) | Технический радар (AOE Technology Radar), роадмап на год, обоснование этапов |
| [Task4](Task4/README.md) | Terraform-конфигурация доменной среды в Yandex Cloud, диаграмма автоматизации развёртывания, обоснование |

Диаграммы описаны в PlantUML, рядом с каждым `.puml` лежит `.png`.
